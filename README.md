# สรุปคลิป — โปรแกรมสรุปวิดีโอ ตัดไฮไลต์ และพากย์เสียงไทย

วางลิงก์ YouTube / TikTok / Facebook / IG / X (หรืออัปโหลดไฟล์) → ได้คลิปสั้นที่ตัดเฉพาะช่วงสำคัญ พร้อมเสียงพากย์สรุปภาษาไทยและซับไตเติล

🎮 **โหมดไฮไลต์เกม MLBB:** ใส่คลิปอัดหน้าจอเล่นเกม (ต้องมีเสียงเกม) โปรแกรมจะหาช็อตเด็ดจากเสียงประกาศในเกม
(First Blood, Double/Triple Kill, Maniac, Savage, Lord …) ถ้าไม่ได้ยินเสียงประกาศจะใช้ช่วงไฟต์ที่เสียงดังแทน
แล้วตัดเป็นคลิปแนวตั้ง 9:16 สำหรับ TikTok/Reels/Shorts ใส่ป้ายตัวใหญ่ตอนเก็บคิล และพากย์แบบแคสเตอร์
(เสียงเกมจะเบาลงอัตโนมัติตอนมีเสียงพากย์) ใส่ชื่อฮีโร่ที่ใช้เพื่อให้บทพากย์ตรงขึ้นได้

🎨 **ตกแต่งคลิป:** สโลว์โมชัน + ซูม + จอสั่น + แฟลชตอนเก็บคิล (โหมดเกม), เพลงประกอบ (อัปโหลดครั้งเดียวใช้ได้ตลอด),
ชื่อช่องและโลโก้มุมจอ, ภาพปกตัวหนังสือใหญ่ (ดาวน์โหลดแยก + ใส่ไว้ต้นคลิปให้เลือกเป็นปก TikTok)

📚 **หลายเกมรวดเดียว:** วางหลายลิงก์ (บรรทัดละลิงก์) หรือเลือกหลายไฟล์ แล้วเลือก "แยกคลิปทุกเกม" หรือ "รวมช็อตเด็ดเป็นคลิปเดียว"

🔒 **PIN:** บน Colab ต้องใส่รหัส PIN (แสดงใต้ปุ่มเปิดโปรแกรม) ก่อนเข้าใช้ ทั้งลิงก์หลักและลิงก์สำรอง

🖼️ **ภาพประกอบโหมดข้อความ:** AI วาด (SDXL-Lightning 1024px) หรือภาพถ่ายจริงจาก Pexels (ใส่คีย์ฟรีจาก pexels.com/api ในช่อง `PEXELS_API_KEY`)
แต่ละฉากกด "🎲 AI วาด 3 ภาพ" / "📷 ภาพถ่ายจริง" / "📁 รูปของฉัน" แล้วแตะเลือกภาพที่ชอบ

🔄 **อัปเดตอัตโนมัติ:** ใส่ `GITHUB_REPO` ในหน้าตั้งค่า Colab แล้วทุกครั้งที่กด Run all จะได้เวอร์ชันล่าสุดเอง

✂️ **แต่งต่อใน CapCut:** หน้าวิดีโอเสร็จมีปุ่ม "ส่งออกสำหรับ CapCut" ได้วิดีโอไม่มีซับ + ไฟล์แยกทีละช็อต
แล้วแชร์เข้าแอป CapCut ได้เลย จากนั้นใช้ "คำบรรยายอัตโนมัติ" ใน CapCut ทำซับจากเสียงพากย์

ติ๊ก **"ทำให้เสร็จอัตโนมัติ"** แล้วโปรแกรมทำให้ครบทุกขั้นจนได้วิดีโอ ไม่ต้องตรวจบทเอง

> ลิงก์ต้องเป็นคลิปสาธารณะ บางครั้ง YouTube บล็อกการดาวน์โหลดจากเซิร์ฟเวอร์คลาวด์ (เช่น Colab) ถ้าเจอ ให้ลองใหม่ภายหลัง หรือดาวน์โหลดคลิปลงเครื่องแล้วอัปโหลดไฟล์แทน
> ถ้าจะโพสต์คลิปสรุปต่อ ควรให้เครดิตเจ้าของคลิปและเคารพลิขสิทธิ์

**ขั้นตอนการทำงาน**
1. **ถอดเสียง** คำพูดในคลิปด้วย Whisper (รันในเครื่อง ฟรี)
2. **AI สรุป** เนื้อหา เลือกช่วงไฮไลต์ และเขียนบทพากย์
3. **ตรวจบท** — คุณแก้บทพากย์ ปรับเวลาเริ่ม/จบ เพิ่ม/ลบช่วงได้ก่อนสร้างจริง
4. **ตัดต่อ + พากย์** ด้วยเสียงไทยของ Microsoft Edge (ฟรี) ลดเสียงต้นฉบับลงเป็นพื้นหลัง ใส่ซับ และเฟดรอยต่อ
5. ดาวน์โหลดไฟล์ MP4

## 💻 ใช้บนคอมพิวเตอร์ — ติดตั้ง (ครั้งเดียว)

**1. ติดตั้ง Python 3.10 ขึ้นไป** — https://www.python.org/downloads/
(Windows: ติ๊ก "Add Python to PATH" ตอนติดตั้ง)

**2. ติดตั้ง ffmpeg**
- Windows: เปิด PowerShell แล้วพิมพ์ `winget install Gyan.FFmpeg`
- Mac: `brew install ffmpeg`
- Ubuntu: `sudo apt install ffmpeg`

**3. ตั้งค่า AI สำหรับสรุป** (เลือกอย่างใดอย่างหนึ่ง)

| ตัวเลือก | ค่าใช้จ่าย | คุณภาพบทพากย์ | วิธีตั้งค่า |
|---|---|---|---|
| **Claude AI** | จ่ายตามการใช้ (คลิปละไม่กี่บาท) | ดีที่สุด | คัดลอก `.env.example` เป็น `.env` แล้วใส่ `ANTHROPIC_API_KEY` จาก https://console.anthropic.com |
| **Ollama** | ฟรี | พอใช้ (ขึ้นกับรุ่น) | ติดตั้ง https://ollama.com แล้วรัน `ollama pull qwen2.5:7b` |
| **ไม่ใช้ AI** | ฟรี | เขียนบทเอง | ไม่ต้องตั้งค่า — โปรแกรมเลือกช่วงให้ แล้วคุณพิมพ์บทเอง |

> การถอดเสียงและเสียงพากย์ฟรีเสมอ ส่วนที่อาจมีค่าใช้จ่ายมีแค่ Claude API ถ้าเลือกใช้

## ใช้งาน

- **Windows:** ดับเบิลคลิก `run.bat`
- **Mac / Linux:** เปิด Terminal ในโฟลเดอร์นี้แล้วรัน `bash run.sh`

ครั้งแรกจะติดตั้งไลบรารีหลายนาที จากนั้นเบราว์เซอร์จะเปิด http://localhost:8000 ให้เอง
(ครั้งแรกที่ถอดเสียง โปรแกรมจะดาวน์โหลดโมเดล Whisper ประมาณ 0.5–1.6 GB)

## เคล็ดลับ

- **ความแม่นยำการถอดเสียง:** `medium` สมดุลดีสำหรับภาษาไทย ถ้ามีการ์ดจอ NVIDIA ใช้ `large-v3-turbo` จะแม่นและเร็ว
  บนซีพียูอย่างเดียว คลิป 10 นาทีอาจถอดเสียงนาน 5–15 นาที
- **บทพากย์ยาวกว่าช่วงคลิป:** โปรแกรมจะต่อภาพจากต้นฉบับให้ หรือหยุดภาพค้างไว้จนพากย์จบ
- **เว้นบทพากย์ว่าง** = ช่วงนั้นใช้เสียงต้นฉบับ (ปรับระดับด้วยแถบ "เสียงต้นฉบับเบื้องหลัง" ตั้ง 100% ถ้าอยากได้ยินชัด)
- ไฟล์งานทั้งหมดอยู่ในโฟลเดอร์ `jobs/` ลบได้ตามต้องการ

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| `ไม่พบ ffmpeg` | ติดตั้งตามข้อ 2 แล้วปิด-เปิดหน้าต่างใหม่ |
| ตัวเลือก Claude ขึ้น "ยังไม่ตั้งค่า" | ตรวจว่าไฟล์ชื่อ `.env` (ไม่ใช่ `.env.txt`) และใส่คีย์แล้ว จากนั้นรันโปรแกรมใหม่ |
| ตัวเลือก Ollama ขึ้น "ยังไม่ตั้งค่า" | เปิดแอป Ollama ก่อน แล้วรีเฟรชหน้าเว็บ |
| สร้างเสียงพากย์ไม่ได้ | edge-tts ต้องต่ออินเทอร์เน็ต |
| ซับไตเติลเป็นสี่เหลี่ยม | ตั้ง `SUB_FONT=` ในไฟล์ `.env` เป็นฟอนต์ไทยที่มีในเครื่อง |

## โครงสร้างไฟล์

```
app.py          เว็บเซิร์ฟเวอร์ + จัดคิวงาน

game.py         โหมดเกม MLBB: หาช็อตเด็ด + บทพากย์แคสเตอร์ (แก้คำ/คะแนนได้ที่ EVENTS)
static/index.html  หน้าเว็บ
```
